# Moss & Stone — Original landing-page demo

An original static website for a fictional home-cleaning business. This source sample shows a responsive, five-section layout with clear service information, a simple process, an FAQ, and an interactive request preview.

[Explore the live demo](https://rabil-launch-studio.rabilabrail.workers.dev/demo/)

## What's included

- A warm cream and forest-green design using system fonts.
- An original inline SVG room illustration.
- Responsive layouts for phones, tablets, and desktop screens.
- Visible keyboard focus, a skip link, labeled controls, and reduced-motion support.
- A local request builder that does not transmit or save data.
- No external fonts, images, packages, analytics, or runtime libraries.

Moss & Stone is fictional. This demo does not offer actual cleaning services, accept bookings, or collect payments. It contains no client logos, testimonials, private data, or claims about real customers.

Open `index.html` in a browser to preview the standalone page. Its asset references are relative. The project is a static frontend and includes no backend, database, payment processor, booking system, domain, or hosting service.

When adapting it for a real business, use accurate service information and connect the contact action to an authorized contact method. The sample request builder intentionally remains local until replaced by a real integration.
